The workspace opens inside this GitHub Pages site. Its Python backend runs on Hugging Face; the direct application link remains available for browsers that restrict embedded sign-in.

One connected civic workspace

The framework includes yearly draft directions and submission locks, exact percentage allocations, problem-by-location heatmaps, source-linked project drafts, scoped government review and separate voluntary contribution pledges.

Fifteen country configurations cover the five original BRICS nations, all permanent UN Security Council members, Norway, Finland, Switzerland, Luxembourg, Japan, Germany and Canada. Every real identity integration requires a country-specific partnership.

1. Citizen

Review fictional yearly tax evidence, edit your directions and confirm a locked submission.

2. Administrator

Process submitted directions into traceable cells without counting them twice.

3. Government

Review proposals in your jurisdiction and publish a reasoned response.

If the local link does not open

The local address only works while the app is running on this computer. Double-click start-framework.cmd in TaxDirection _ HuggingFace. No package installation is required for the local framework.

Or open a terminal in that directory and keep this command running:

python -m framework.server --demo

Then visit http://127.0.0.1:8787/. Closing that terminal stops the manual server; using the Windows launcher avoids that problem.

A clearly labelled pilot

The demo contains fictional data and shared demonstration accounts. No real tax ID is verified, no payment is collected and no proposal is delivered to an external government service. The illustrative allowance is an advisory preference weight, not an approved right to redirect tax revenue.

Hosted demonstration data may reset when a Space restarts unless appropriate durable storage is configured. Never enter real tax or identity information.
